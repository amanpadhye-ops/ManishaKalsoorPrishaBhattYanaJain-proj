# IntelliConvene | Brand, Market & Audience Diagnosis (ADBR205)

Phase 1 group assignment, built as a static website (HTML, CSS, JavaScript). No build step.

## Pages
- `index.html` Section A, IntelliConvene (home)
- `marketing.html` Section B, Marketing Communication
- `market.html` Section C, Market
- `stakeholders.html` Section D, Stakeholder Issues

## Publish on GitHub Pages
1. Create a repository and upload the contents of this folder to the repository root.
2. Go to Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. The site goes live at `https://<username>.github.io/<repository>/` within a minute or two.

## Quick edits
- Group name appears in the footer of each HTML file. Find and replace `Group Name`.
- Brand colours and fonts sit in the `:root` block at the top of `style.css`.
